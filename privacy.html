Privacy Policy

Last updated: November 11, 2026

Purpose

This personal integration uses the Google Drive API through Rclone for file management, transfers, synchronization, backups and integrity checks.

Data Access

The application accesses Google Drive files only with authorization from the account owner.

Data Storage

OAuth credentials and tokens are stored locally in the user's Rclone configuration. Files may be copied to destinations selected by the account owner.

Data Sharing

Google user data is not sold or used for advertising. Data is transferred only to destinations chosen by the account owner.

Data Retention

The account owner controls file retention and may revoke OAuth authorization through Google Account security settings.

Website

This website provides information about the integration and does not collect Google Drive files.
